为什么单独打开一个 Chrome 窗口？

Google 拒绝在程序内嵌的浏览器里登录（会提示“此浏览器或应用可能不安全”），所以 YouTube / TikTok 改用本机 Chrome 的独立窗口。

  • 首次打开时，在这个 Chrome 窗口里登录一次 Google / TikTok；
  • 登录状态保存在本机 chrome-profile，以后启动程序不用重复登录；
  • 关闭程序时这个 Chrome 窗口会一起关闭，不影响你日常使用的 Chrome。

如果登录过期，在该窗口重新登录一次即可。
